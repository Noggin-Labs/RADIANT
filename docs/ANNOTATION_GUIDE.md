# Annotation guide (draft)

## Purpose

Create defensible reference labels for mathematical reasoning scenarios. This guide is a draft and requires review by an independent mathematics educator/reviewer before research use.

## Label rules

- `correct_reasoning`: the supplied steps validly solve the stated problem.
- `invalid_intermediate_operation`: at least one shown operation is mathematically invalid and affects the derivation.
- `conceptual_misunderstanding`: use only when the written work provides affirmative evidence of a specific conceptual misconception; do not infer it from a wrong answer alone.
- `arithmetic_error`: the method is valid but a numerical computation is incorrect.
- `insufficient_evidence`: the provided work does not support a unique diagnosis.

Labels may need to become problem-specific; do not force every response into this small illustrative taxonomy.

## Evidence

For every diagnosis, annotate the smallest step or set of steps that supports it. Evidence must be present in the learner's submitted work. If no step supports a diagnosis, use an underdetermined scenario.

## Independent review

Two reviewers independently label each scenario. Record the original labels, disagreement, adjudicated label, rationale, and reviewer role. Report agreement with an appropriate statistic and its limitations; do not rely on percentage agreement alone.

## Prohibitions

Do not infer a learner's stable ability, disability, motivation, or personal traits from a single mathematical response. These labels describe a response in a particular task context, not the learner as a person.
